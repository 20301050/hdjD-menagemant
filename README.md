# HDJ Déménagements France – Europe

Site vitrine de HDJ Déménagements (Mitry-Mory, 77290) : déménagement de particuliers et d'entreprises, location de camion 20 m³ et 30 m³ avec chauffeur, monte-meubles, garde-meuble, vente de matériel.

- Version française : `index.html`
- Version anglaise : `en.html`
- Liste des villes du calculateur de distance : `js/villes.js`

Ancienne version du site : branche `ancienne-version`.
