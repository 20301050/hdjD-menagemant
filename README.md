# HDJ Déménagements France - Europe

Site vitrine de **HDJ Déménagements**, spécialiste du déménagement en France et en Europe, réalisé par **Malgorzata Kieliszek**, cheffe de projet digital & e-merchandising.

## Contenu
- `index.html` : le site complet (accueil, formules, camions, services, guide), navigation par menu
- `images/` : photos du site
- `videos/` : vidéo de présentation du guide

Bleu `#193E65` · accent rouge `#D62828`, validés par le client.

## Mettre le site en ligne avec GitHub Pages
1. Créer un nouveau dépôt sur GitHub (par exemple `hdj-demenagements`).
2. **Add file › Upload files** : glisser `index.html`, `README.md` et les dossiers `images` et `videos`, puis **Commit changes**.
3. **Settings › Pages** : branche `main`, dossier `/ (root)`, puis **Save**.
4. Le site est en ligne après une ou deux minutes à l'adresse `https://ton-pseudo.github.io/hdj-demenagements/`.
